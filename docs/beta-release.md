# v0.1 Beta 内测说明

## 发布范围

- 版本：`0.1.0-beta.1`
- 平台：Windows x64 Electron 桌面版
- 分发：受邀人员通过私有 GitHub Release 获取签名安装包
- 更新：Beta 不使用自动更新；新版本发布后从私有 Release 手动安装

## 首次使用

1. 从私有 Release 下载并验证安装包的 SHA-256 校验值。
2. 导入自己的 PDF 或 EPUB 教材。
3. 在设置中选择本机 Ollama、OpenAI 兼容服务、Codex 或 Claude。
4. 使用外部智能来源前，确认教材内容会发送给所选服务商。

没有连接模型时，教材导入、阅读、本地检索、笔记和基础学习记录仍可使用。

## 隐私边界

知页不会后台上传教材、笔记、聊天记录或行为统计。使用外部智能来源时，仅发送当前任务所需的教材原文；图示讲解会额外发送当前 PDF 页面图像。API Key 和 Claude 令牌不会写入学习备份或智能来源日志。

遇到错误时，请在应用中主动点击“导出诊断”。诊断文件只包含版本、系统、来源配置状态、错误码和经过清理的错误详情。提交前仍请人工确认没有敏感内容。

## 反馈格式

请通过 GitHub Bug 报告提交：

- Beta 版本和安装包架构
- Windows 版本、设备类型和是否首次安装
- 可复现步骤和预期/实际结果
- 是否使用外部智能来源
- “导出诊断”文件内容

不要提交教材文件、教材原文、笔记、聊天记录、API Key、Token、完整服务地址或备份文件。

## 已知限制

- 仅支持 Windows x64。
- 外部模型需要用户自行安装、登录或配置 API Key。
- 扫描版 PDF 可能需要启用本地 OCR，识别速度取决于设备性能。
- Beta 暂不提供收费、账号、云同步和自动更新。

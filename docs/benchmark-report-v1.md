# 知页 Benchmark 教材测试集 v1.0 - 首轮报告

测试日期：2026-08-02（Asia/Shanghai）

## 结论

真实文件兼容性基线已建立，16 个可重复的结构解析、限制与检索检查全部跑通；独立 OCR 严格检查未通过，仅命中 8 个医学关键项中的 6 个。

“能导入”不等于“足够可靠”。首轮测试确认了 4 个需要优先处理的质量缺口：

1. 混合型 PDF 中的纯图片页会被静默漏掉；即使用户勾选 OCR，当前流程也只在整本 PDF 完全无文字时回退 OCR。
2. Tesseract.js 将“碳酸氢根”识别为“碳酸毛根”，将 `β1` 识别为 `B1`；这两类错误会直接污染医学问答。
3. 三份真实英文论文 PDF 均只得到 1 个章节、0 个小节，说明现有标题识别主要适配中文教材，对英文 `1 Introduction` / `2 Method` 结构无效。
4. 450 页公版扫描医学教材虽然带 OCR 文本层并成功导入，但 444 个有文字页产生了 14,182 个块和 529 个“表格块”；对旧式多栏扫描本存在明显的过度表格判定风险。

另有一个错误分类问题：缺失 CMap 的 PDF 被提示为“可能是扫描版，请启用 OCR”。它实际是字体编码损坏，OCR 可以作为补救，但错误信息不够准确。

## 检索与引用

- `SB、AB、BE 分别是什么？` 返回第 1 页，关键词与页码正确。
- `β受体阻断药为什么降低心率？` 返回第 2 页，关键词与页码正确。
- TabLeX 与 PubTabNet 英文问题均能召回预期首页，但多个候选的分数全部饱和到 `1.000`，排序区分度不足；需要在后续版本加入 MRR/nDCG 和首条命中断言。
- 本轮只验证了解析、检索和引用定位，没有调用外部 LLM 生成答案；因此不能把结果表述为“问答正确率”。

## OCR 严格检查

Tesseract.js 使用 `chi_sim + eng`，扫描页轻微倾斜 0.7°：

- 置信度：82%
- 关键项命中：6/8
- 成功：`代谢性酸中毒`、`酸负荷增加`、`肾排酸障碍`、`Na+`、`HCO3-`、`PaCO2`
- 失败：`碳酸氢根丢失`、`β1`
- 用时：2.67 s（模型已在本次运行中加载）

该检查故意以非零状态结束，防止 CI 把“普通句子大致可读”误当成“医学术语可靠”。
